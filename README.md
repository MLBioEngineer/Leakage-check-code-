# Leakage Check

This repository contains a Jupyter Notebook for checking data leakage in a machine learning workflow.

## Structure

```
leakage_check_github_repo/
│
├── notebooks/
│   └── leakage_check.ipynb
│
├── README.md
└── requirements.txt
```

## Usage

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Open the notebook:

```bash
jupyter notebook notebooks/leakage_check.ipynb
```

## Purpose

The notebook is prepared for investigating potential data leakage issues during model development and evaluation.
